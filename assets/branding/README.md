不使用 Steam/Valve 的机械连杆图形或 Nintendo Switch/Joy-Con 标志。

- `icon-source.png`：生成原稿。`icon.jpg`：256×256、RGB baseline JPEG、去除 EXIF，供 hbmenu NRO 与 NSP HOME 图标共用。

## Icon prompt

Use case: logo-brand. Create one original finished launcher icon for the independent homebrew game-streaming app NSteamLink. Square 1024x1024, opaque full-bleed graphite-black background. A single bold geometric folded ribbon forms an abstract capital N with a small right-pointing play-shaped negative space integrated naturally into the mark. Beautiful precise edges, large simple silhouette recognizable at 48px; quiet dimensional shading, restrained mint-to-cyan main ribbon with one small warm coral facet and a violet reflected edge. Sophisticated console application identity, centered mark occupying about 65% of the image, generous safe margin. No words or lettering beyond the abstract symbol, no border, no mockup, no external rounded-square frame. Do not use, resemble, or adapt Steam's mechanical linkage/circle logo, Valve logos, Nintendo Switch/Joy-Con symbols, or any other existing brand logo. Deliver only the single icon artwork.

## Background prompt

Use case: logo-brand. The attached artwork is a style reference for NSteamLink, not an edit target. Create a matching original 16:9 widescreen background for this independent game-streaming app, at 1536x864 or a larger 16:9 size. Opaque graphite black background with subtle dimension. Use two extremely restrained, broad folded ribbon forms near the extreme lower-right and upper-left corners, sharing the reference's mint/cyan, warm coral and violet shading, but much darker and lower contrast. Keep the central 75% of the canvas nearly uniform dark graphite so large white interface text stays readable. Quiet premium console UI atmosphere. Do not place the icon or any central symbol in the background. No words, letters, UI elements, frame, screenshots, Steam linkage logo, Valve or Nintendo symbols. Deliver only the finished background artwork.
